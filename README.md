# Демоэкзамен: два проекта

Репозиторий содержит два самостоятельных учебных проекта на PHP и MySQL/MariaDB для XAMPP.

**Для виртуальной машины с XAMPP в `/opt/lampp` откройте [инструкцию для РЕД ОС](REDOS.md).** Получите проекты прямо из GitHub через Git или по отдельным файлам, затем проверьте обе базы и вход.

Версии PHP и MariaDB, результаты проверки двух сайтов и ограничения среды приведены в [отчёте от 19 ноября](Проверка%20проектов.txt).

| Папка | Проект | Содержимое |
|---|---|---|
| [первая часть](первая%20часть/) | «Корочки.есть» — запись на курсы | Исходники, изображения, начальная SQL-база, инструкция, ER-диаграмма и отчёт проверки |
| [часть вторая](часть%20вторая/) | «Мероприятия» — запись на мероприятия техникума | Приложение, модели БД, CSV, разбор задания, макеты, изображения и чек-лист проверки |

## Запуск

Нужны XAMPP, PHP 8.2+, расширения `pdo_mysql`, `mbstring`, работающий MySQL/MariaDB. Все CSS, JavaScript и изображения включены в проекты; подключение к интернету для работы сайтов не требуется.

1. Скопировать содержимое `первая часть` в `xampp/htdocs/korochki`.
2. Скопировать содержимое `часть вторая/приложение` в `xampp/htdocs/events`.
3. В phpMyAdmin импортировать `первая часть/korochki_db.sql` и `часть вторая/приложение/database/college_events.sql` в новую локальную установку. Это две разные базы: `korochki_db` и `college_events`.
4. При необходимости исправить локальные параметры подключения в `первая часть/config.php` и `часть вторая/приложение/config.php`. В комплекте параметры стандартной учебной установки XAMPP: `127.0.0.1`, порт `3306`, пользователь `root`, пустой пароль.
5. Запустить Apache и MySQL в XAMPP и открыть `http://localhost/korochki/` или `http://localhost/events/`.

Начальная учётная запись администратора обоих учебных проектов: **Admin / KorokNET** — задана демонстрационным ТЗ. Пароли в SQL и CSV хранятся как хеши.

Не импортировать начальную SQL-схему поверх существующей рабочей базы. Альтернатива для второй части — CLI-импорт `database/setup.php` по инструкции в её README; для него рядом нужна папка `импорт CSV`. Импортировать SQL и затем те же CSV повторно не нужно.

## Материалы второй части

- `материалы` — исходное ТЗ, цветовая разметка DOCX/PDF/HTML, концептуальная и логическая модели, ER-диаграмма, объяснение 3НФ, аудиты и снимки интерфейса.
- `импорт CSV` — восемь импортных таблиц и порядок загрузки.
- `макеты HTML` — шесть демонстрационных страниц; формы в этих макетах не отправляются.
- `Запустить.cmd`, `Остановить.cmd`, `start.ps1`, `stop.ps1` — вспомогательный запуск в Windows. Для нестандартного каталога XAMPP задайте переменную среды XAMPP_HOME.

## История и состав публикации

Сохранены исходные коммиты второй части. Последующий коммит переносит её файлы в папку `часть вторая` и добавляет готовую первую часть. Отдельных вложенных Git-репозиториев и подмодулей нет.

Не включены ранняя версия сайта, XAMPP, журналы, служебная `.runtime` и резервная копия рабочей БД с пользовательскими заявками. Начальные SQL/CSV содержат справочники и заданного администратора. Данные на снимках аудита — синтетические тестовые записи.

Отчёты аудита отражают состояние на даты их выполнения. Их старые замечания об отсутствии публикации относятся к периоду до объединения проектов. История начала и завершения каждого экзаменационного модуля задним числом не создавалась. Доступ к общему экзаменационному серверу и официальным ZIP-приложениям не предоставлялся; связанные ограничения указаны в отчётах.
