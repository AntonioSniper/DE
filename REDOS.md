# Как запустить «Корочки.есть» и «Мероприятия» на РЕД ОС

Результат — два сайта в браузере виртуальной машины: [Корочки.есть](http://localhost/korochki/) и [Мероприятия](http://localhost/events/). Все команды ниже выполняются **в терминале внутри РЕД ОС**. Для установки нужны права `sudo`, XAMPP для Linux с PHP 8.2 или новее и две папки из этого репозитория.

## 1. Перенесите проекты

**С интернетом и Git.** Для первого скачивания откройте терминал и выполните:

```sh
cd ~
git clone https://github.com/AntonioSniper/DE.git DE-current
cd DE-current
```

Если вы уже клонировали репозиторий, откройте терминал в существующей папке с его `README.md` и выполните `git pull --ff-only`. Если Git сообщает о конфликте с локальными правками, сохраните свою копию и скачайте свежий ZIP в отдельную папку.

**Без интернета в виртуалке.** На компьютере с интернетом скачайте [ZIP ветки main](https://github.com/AntonioSniper/DE/archive/refs/heads/main.zip). Передайте архив через флешку или общую папку, распакуйте его **в домашнюю папку пользователя РЕД ОС**. Откройте распакованную папку `DE-main` и выберите «Открыть в терминале». При двойной вложенности зайдите туда, где рядом лежат `README.md`, `первая часть` и `часть вторая`.

Проверьте, что терминал открыт в нужном месте. Должны появиться **оба** имени:

```sh
ls -d "первая часть/korochki_db.sql" "часть вторая/приложение/database/college_events.sql"
```

## 2. Запустите XAMPP внутри РЕД ОС

Если «Мероприятия» на этой виртуалке уже открывались через XAMPP, используйте ту же установку. Стандартный каталог — `/opt/lampp`. Если XAMPP ещё нет, на компьютере с интернетом скачайте установщик **XAMPP for Linux x64** с PHP 8.2 или новее, перенесите его в виртуалку. В отдельном терминале в папке с установщиком выполните `chmod +x имя-файла.run`, затем `sudo ./имя-файла.run`, подставив настоящее имя файла, и завершите мастер. Вернитесь в терминал с проектами. [Загрузка XAMPP](https://www.apachefriends.org/download.html) · [Инструкция Apache Friends для Linux](https://www.apachefriends.org/faq_linux.html)

Выполните этот блок. Если установка лежит в другом каталоге, измените первую строку. Сохраните этот терминал открытым до конца инструкции.

```sh
XAMPP=/opt/lampp
sudo "$XAMPP/lampp" start
sudo "$XAMPP/lampp" status
"$XAMPP/bin/php" -r 'printf("PHP %s | pdo_mysql: %s | mbstring: %s\n", PHP_VERSION, extension_loaded("pdo_mysql") ? "OK" : "нет", extension_loaded("mbstring") ? "OK" : "нет");'
```

Продолжайте, когда Apache и MySQL/MariaDB запущены, версия PHP не ниже 8.2 и оба расширения показывают `OK`. Проверьте, что в браузере **внутри виртуалки** открывается [phpMyAdmin](http://localhost/phpmyadmin/).

## 3. Скопируйте сайты в Apache

Вставьте блок целиком в тот же терминал. Он создаёт каталоги сайтов, переносит страницы, картинки и скрытые `.htaccess`. На уже настроенной виртуалке он обновляет файлы и сохраняет действующий `config.php` каждого сайта. Если вы вручную меняли сам код сайта на виртуалке, перед этим сохраните свою версию отдельно.

```sh
(
  set -eu
  test -f "первая часть/korochki_db.sql"
  test -f "часть вторая/приложение/database/college_events.sql"
  test -d "$XAMPP/htdocs"

  copy_site() {
    src=$1
    dst=$2
    sudo mkdir -p "$dst"
    for item in "$src"/* "$src/.htaccess"; do
      if [ "$item" = "$src/config.php" ] && [ -f "$dst/config.php" ]; then
        continue
      fi
      sudo cp -R -- "$item" "$dst/"
    done
  }

  copy_site "первая часть" "$XAMPP/htdocs/korochki"
  copy_site "часть вторая/приложение" "$XAMPP/htdocs/events"
  echo "Оба сайта скопированы."
)
```

Дождитесь сообщения «Оба сайта скопированы». В папке `htdocs/korochki` теперь лежат `index.php` и каталог `pages`, а в `htdocs/events` — `index.php`, `login.php`, `admin.php` и остальные страницы. Адреса сайтов задаются именами каталогов в `htdocs`.

## 4. Подготовьте две базы

Откройте [phpMyAdmin](http://localhost/phpmyadmin/) и посмотрите список баз слева. **Проверяйте каждый проект отдельно.** Если «Мероприятия» уже работают и в `college_events` есть таблицы и заявки, пропустите импорт для этой базы. То же правило действует для `korochki_db`. Исправления сайтов совместимы с прежней схемой.

| Проект | База по умолчанию | Файл из скачанного репозитория |
|---|---|---|
| Корочки.есть | `korochki_db` | `первая часть/korochki_db.sql` |
| Мероприятия | `college_events` | `часть вторая/приложение/database/college_events.sql` |

Для каждой **отсутствующей или пустой** базы нажмите значок домика в phpMyAdmin → **Импорт** → **Выберите файл**. Укажите соответствующий SQL из таблицы, кодировку UTF-8 и нажмите кнопку импорта внизу. Дождитесь сообщения об успешном выполнении. SQL сам создаёт базу и выбирает её. Для импорта нужна учётная запись MariaDB с соответствующими правами. При частичной старой установке сначала сохраните данные и разберитесь с существующими таблицами.

После установки SQL в `korochki_db` будет 7 таблиц, в `college_events` — 8. В каждой базе в таблице `users` у новой установки есть запись с логином `Admin`. SQL второй части уже включает данные из CSV.

Оба сайта по умолчанию подключаются к MariaDB по `127.0.0.1:3306` от пользователя `root` с пустым паролем. Если на виртуалке другие настройки, откройте **установленные** конфигурации и укажите реальные `host`, `port`, `database`, `username` и `password`:

```sh
sudoedit "$XAMPP/htdocs/korochki/config.php"
sudoedit "$XAMPP/htdocs/events/config.php"
```

## 5. Проверьте результат

| Сайт | Главная | Вход | Данные администратора начальной базы |
|---|---|---|---|
| Корочки.есть | [Открыть](http://localhost/korochki/) | [Войти](http://localhost/korochki/pages/auth.php) | `Admin` / `KorokNET` |
| Мероприятия | [Открыть](http://localhost/events/) | [Войти](http://localhost/events/login.php) | `Admin` / `KorokNET` |

1. Откройте обе главные страницы. Должны появиться оформление и слайдер с изображениями. Для быстрой проверки путей отдельно откройте [первую картинку «Корочек»](http://localhost/korochki/media/slides/slide-1.webp) и [первую картинку «Мероприятий»](http://localhost/events/assets/slide-1.webp).
2. Войдите в каждую админку. Появится «Панель администратора». На свежей базе список заявок пуст.
3. Для проверки записи в БД откройте приватное окно, зарегистрируйте учебного пользователя и подайте заявку. Обновите админку в обычном окне — появится заявка со статусом «Новая». Такая проверка добавляет запись в выбранную базу.

После перезагрузки виртуалки достаточно снова запустить XAMPP командой `sudo /opt/lampp/lampp start` и открыть сайты. Копирование и импорт выполняются при установке. Если использовали свой путь к XAMPP, подставьте его и здесь.

## Если результат отличается

| Что видно | Что проверить |
|---|---|
| Появляется только текст «Корочек» | Откройте [файл стилей](http://localhost/korochki/styles/style.css). Если виден CSS, обновите страницу сочетанием Ctrl+F5. Если ответ 404 или браузер запрашивает старый адрес `/DE/korochki/`, откройте именно `http://localhost/korochki/` и повторите шаг 3 из свежей копии. |
| Главная или страница входа возвращает 404 | Проверьте структуру из шага 3. Например, файл второй части должен лежать прямо в `htdocs/events/login.php`. |
| Страница открывается, но пишет об ошибке БД | Проверьте статус MariaDB, наличие таблиц из шага 4 и параметры в установленном `config.php` нужного проекта. Для существующего сайта используйте его рабочие данные подключения. |
| XAMPP сообщает, что порт занят | Команда `sudo ss -ltnp` покажет, кто слушает порты 80, 443 и 3306. На учебной ВМ используйте экземпляр сервера, выделенный для проектов. Если Apache настроен, например, на 8080, добавьте `:8080` ко всем адресам браузера. |
| Apache отвечает 403 или 500 | Сразу после запроса посмотрите последние строки журнала командой `sudo tail -n 40 "$XAMPP/logs/error_log"`. Проверьте каталог сайта, права чтения файлов и право входа в каталоги. При сообщении о директиве `.htaccess` проверьте настройки `AllowOverride` для `htdocs`. Для настройки системного Apache и SELinux есть [документация РЕД ОС](https://redos.red-soft.ru/base/redos-8_0/8_0-network/8_0-sett-web-servers/8_0-apache-install/). |
