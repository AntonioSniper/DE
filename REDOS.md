# Запуск двух проектов на виртуальной машине РЕД ОС

XAMPP уже установлен в `/opt/lampp`. Откройте **терминал внутри виртуальной машины**. Получите проекты одним из двух способов ниже. Команды установки запускайте от обычного пользователя: при копировании в `htdocs` система сама запросит пароль через `sudo`.

## 1. Получите файлы и запустите сайты

**Если Git на виртуалке работает**, скопируйте весь блок в терминал:

```sh
cd ~ && git clone --depth 1 https://github.com/AntonioSniper/DE.git DE-redos && bash DE-redos/install-redos.sh
```

Если этот репозиторий уже клонирован, откройте терминал в папке с его `README.md` и выполните:

```sh
git pull --ff-only && bash install-redos.sh
```

Дождитесь сообщения **«Код обоих сайтов скопирован»** и переходите к шагу 2. Скрипт запускает XAMPP и копирует файлы в `/opt/lampp/htdocs/korochki` и `/opt/lampp/htdocs/events`. При повторной установке он сохраняет оба действующих `config.php`. Локальные правки в других файлах сайта перед обновлением сохраните отдельно.

**Если `git clone` недоступен**, используйте запасной способ. Для него нужны `curl`, `python3` и доступ из терминала к `api.github.com` и `raw.githubusercontent.com`. Этот блок берёт отдельные файлы двух сайтов из одной версии репозитория, включая картинки, стили, SQL и скрытые `.htaccess`. Каждый файл сверяется с контрольной суммой GitHub до установки.

```sh
cd ~ && curl -fL --retry 2 https://raw.githubusercontent.com/AntonioSniper/DE/main/fetch-redos.py -o fetch-redos.py && python3 fetch-redos.py DE-files && bash DE-files/install-redos.sh
```

Команда рассчитана на новую папку `DE-files`. Если такая папка уже есть, укажите новое имя в обоих местах. При обрыве загрузки команда остановится до копирования файлов в XAMPP. Если оба способа сообщают об отсутствии сетевого доступа, проверьте, есть ли уже актуальная копия на виртуалке. При наличии в ней `install-redos.sh` откройте терминал в этой папке и выполните `bash install-redos.sh`. Для получения новой версии нужен хотя бы один доступный способ чтения файлов репозитория.

## 2. Проверьте базы в phpMyAdmin

Откройте [phpMyAdmin внутри виртуалки](http://localhost/phpmyadmin/). Посмотрите базы в списке слева. Решение об импорте принимайте **для каждой базы отдельно**.

| Проект | База | Файл для первой установки |
|---|---|---|
| Корочки.есть | `korochki_db` | `/opt/lampp/htdocs/korochki/korochki_db.sql` |
| Мероприятия | `college_events` | `/opt/lampp/htdocs/events/database/college_events.sql` |

- **База уже работала и содержит таблицы.** Пропустите импорт. В частности, если «Мероприятия» на этой ВМ работали, достаточно обновить их код.
- **База отсутствует или пуста.** В phpMyAdmin нажмите значок домика → **Импорт** → **Выберите файл**. Укажите SQL из таблицы и нажмите **Импорт** внизу. SQL сам создаст и выберет нужную базу. В Linux в окне выбора файла обычно можно нажать Ctrl+L и вставить полный путь.
- **Старый импорт оборвался.** Сначала сохраните существующие данные и проверьте, каких таблиц не хватает. В полной установке у «Корочек» 7 таблиц, у «Мероприятий» — 8.

## 3. Откройте оба сайта

| Сайт | Главная | Вход администратора |
|---|---|---|
| Корочки.есть | [Открыть](http://localhost/korochki/) | [Войти](http://localhost/korochki/pages/auth.php) |
| Мероприятия | [Открыть](http://localhost/events/) | [Войти](http://localhost/events/login.php) |

Данные администратора из начальной базы для обоих сайтов — логин **`Admin`**, пароль **`KorokNET`**. На главных должны отображаться оформление и слайдер. После входа появится панель администратора. Чтобы отдельно проверить прежнюю проблему с путями, откройте [стили «Корочек»](http://localhost/korochki/styles/style.css) и [первую картинку слайдера](http://localhost/korochki/media/slides/slide-1.webp).

**После перезагрузки виртуалки** достаточно запустить `sudo /opt/lampp/lampp start` и открыть сайты в браузере. С этого момента для работы сайтов GitHub не требуется.

## Если что-то не открылось

| Что произошло | Что проверить |
|---|---|
| Git пишет `destination path ... already exists` | Для существующей Git-копии используйте команду обновления из шага 1. Если это другая папка, выберите новое имя для клонирования. |
| Не открывается даже phpMyAdmin | Выполните `sudo /opt/lampp/lampp status`. Для работы нужны Apache и MySQL/MariaDB. При ошибке Apache посмотрите `sudo tail -n 40 /opt/lampp/logs/error_log`. |
| Главная открывается без оформления или фото | Откройте ссылку на картинку из шага 3. При 404 проверьте, что установка дошла до сообщения об успешном копировании. Если картинка открылась, обновите главную через Ctrl+F5. Используйте адрес `/korochki/`. |
| Сайт сообщает об ошибке базы | Проверьте импорт из шага 2 и параметры в установленном `config.php` нужного сайта. Начальные значения — хост `127.0.0.1`, порт `3306`, пользователь `root`, пустой пароль. Для настроенной MariaDB укажите её действующие данные. |

Справка по командам XAMPP доступна у [Apache Friends](https://www.apachefriends.org/faq_linux.html).
