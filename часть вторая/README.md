# Мероприятия — часть вторая

Готовое приложение PHP 8.2 + MariaDB/MySQL. Библиотека Bootstrap хранится локально. Интернет для запуска не нужен.

## Запуск на этом компьютере
Дважды нажать «Запустить.cmd» в этой папке. Затем открыть http://127.0.0.1:8081 .
Скрипт ищет XAMPP в стандартной папке на системном диске и в Documents/Codex/xampp. Для другой установки задайте переменную среды XAMPP_HOME.
Администратор: **Admin / KorokNET**. Обычный пользователь регистрируется самостоятельно.
Для завершения нажать «Остановить.cmd». Уже работающий до запуска скрипта MySQL этот скрипт не останавливает.

## Apache / XAMPP
В RED ОС скопируйте содержимое папки «приложение» в каталог сайта вашего Apache, например htdocs/events в установленном XAMPP. Импортируйте database/college_events.sql в новую БД, проверьте config.php и откройте http://localhost/events/. Главная, регистрация, вход, подача заявки, личный кабинет и панель администратора находятся в index.php, register.php, login.php, apply.php, my.php и admin.php соответственно.

## Состав комплекта
- материалы: оригинальный текст, DOCX/PDF/HTML с семью цветами, отдельные XLSX с концептуальной моделью, логической моделью и восемью импортными листами, ER-диаграмма из phpMyAdmin, мобильные снимки, результаты проверок.
- импорт CSV: восемь CSV и порядок импорта.
- приложение: PHP, локальные CSS/JS/изображения, схема, начальные данные, CLI-импорт.
- макеты HTML: шесть самостоятельных страниц с локальными ресурсами; формы демонстрационные. Показанные заявки синтетические и удалены из рабочей БД после проверки.

## Перенос на другой компьютер
Установить XAMPP с PHP 8.2 и MySQL/MariaDB, включить pdo_mysql и mbstring. Скопировать папку приложение в htdocs/events. Импортировать приложение/database/college_events.sql в пустую базу через phpMyAdmin либо выполнить PHP CLI database/setup.php, сохранив рядом папку импорт CSV. Настроить config.php при других параметрах БД. Включить Apache/MySQL, открыть /events/.
Не импортировать начальную SQL-схему поверх рабочей базы. CLI-установщик проверяет наличие таблицы users и останавливается без перезаписи.

## Проверка требований
Реализованы пять заданных событий, регистрация/авторизация, заявки с командой и контактами, дата с маской и календарём, статус Новая, изменения администратором, фильтры по типу/статусу, всплывающие сообщения, по три заявки на страницу со стрелками, отзыв владельца только после «Участие подтверждено». Слайдер: три изображения 1280×720, 2000 мс, стрелки. При настройке ОС «уменьшить движение» автопрокрутка стартует на паузе, пользователь может включить её кнопкой.
Проверено 72 HTTP-сценария после исправлений и шесть страниц при viewport 414×896. ER-диаграмма открыта и сохранена в конструкторе phpMyAdmin. Две модели, SQL и CSV используют одинаковые восемь таблиц. Приложение использует ООП, PDO, подготовленные запросы, CSRF и хеширование паролей.
В модуле 1 названа кнопка «Создать пользователя», а в модуле 2 — «Зарегистрироваться». В итоговом интерфейсе использован вариант модуля 2.

## Изображения и оформление
Три изображения созданы генератором по разрешению пользователя, исходники и описания сохранены в материалах. Они заменяют не предоставленные ZIP-приложения к экзамену; совпадение с официальным комплектом изображений не заявляется. WebP оптимизированы до суммарно 309 594 байт, размеры одинаковые.
Для категории «Требования к данным» выбран бледно-красный: в легенде документа-примера цвет этой строки отсутствовал. Остальные семь категорий и цвета описаны в самом разборе.
