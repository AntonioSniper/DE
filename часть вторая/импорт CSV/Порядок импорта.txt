Кодировка: UTF-8. Разделитель: запятая. Кавычки: двойные. Первая строка — имена полей.
Порядок: roles → event_types → events → statuses → users → applications → application_members → reviews.
Сначала создать таблицы через приложение/database/schema.sql. При ручном импорте CSV пропустить первую строку, разделитель запятая. Ячейки с запятыми заключены в кавычки по RFC4180.
Автоматический импорт: запустить PHP CLI для приложение/database/setup.php. Скрипт использует имя БД из config.php (по умолчанию college_events) и проверяет, что в ней ещё нет таблиц. Не импортировать поверх уже заполненной базы.
Альтернатива CSV: импортировать приложение/database/college_events.sql через phpMyAdmin в новую базу. Это схема и те же исходные данные; повторно CSV после SQL не импортировать.
users.csv содержит только заданного администратора Admin / KorokNET. Пароль хранится как bcrypt-хеш. Контакты администратора технические, не персональные.
applications.csv, application_members.csv, reviews.csv содержат заголовки без выдуманных заявок и отзывов. Данные появятся при работе сайта.
Дата заявки хранится DATE (ГГГГ-ММ-ДД); в интерфейсе ДД.ММ.ГГГГ. В ТЗ нет фиксированных дат событий, поэтому дата относится к заявке.

Структура согласована с восемью листами логической модели (3НФ). См. материалы/Нормализация 3НФ.txt.
