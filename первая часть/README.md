# Корочки.есть

Сайт: http://localhost/korochki/

Исходники этого проекта находятся в папке «первая часть» общего репозитория.
XAMPP: C:\Users\danya\Documents\Codex\xampp. Запуск: xampp-control.exe → Start у Apache и MySQL.
Администратор: Admin / KorokNET. Обычный пользователь регистрируется на сайте.

Для переноса скопируйте korochki в XAMPP/htdocs/korochki, импортируйте korochki_db.sql в пустую БД и проверьте config.php. Нужны PHP 8.2+, pdo_mysql и mbstring. Не импортируйте SQL повторно поверх существующих таблиц. Bootstrap, JS и изображения локальные.

Требования сверены с присланным оригиналом и шестью листами draw.io. Регистрация, вход, свои заявки, обучение, текстовый отзыв внутри завершённой заявки, панель администратора с фильтрами и статусами. В кабинетах по три заявки на страницу. Маски телефона/даты и календарь сохранены.

Полная таблица соответствия, отличия от draw.io и незавершённые пункты сдачи: docs/AUDIT.md. Актуальные снимки всех шести страниц 390×844: docs/screenshots. Снимок ER-диаграммы СУБД: docs/er-phpmyadmin.jpg. Оригинальные материалы в соседней папке «Все данные для создания» не изменены.
