# Индивидуальное оформление

Изменён только styles/style.css. Сохранены структура draw.io, персиковая шапка #ffcc99, голубые хлебные крошки #dae8fc и фиолетовая гамма навигации. Добавлены тёплый фон, заголовки Georgia, сливовые основные кнопки, тонкие рамки, небольшой срез углов и оформление карточек в стиле учебного блокнота.

Маски, календарь, три заявки на странице, отзывы, формы и правила доступа сохранены. Проверены административные карточки на широком экране и формы при 390×844; горизонтального переполнения нет. Новые библиотеки и внешние шрифты не подключались.

Снимки предыдущей проверки в docs/screenshots отражают предыдущую косметическую версию. Актуальные образцы оформления находятся в этой папке.
