# Сверка с оригиналом и draw.io

Проверено 6 ноября 2026 года по присланному «Вставленный текст.txt» и всем шести листам «Копия Корочки.drawio.xml». Репозиторий не использовался как источник требований. Модуль 2 уточняет модуль 1: курс из списка, кнопка «Зарегистрироваться».

Функциональная часть проверена; найденные расхождения исправлены. Полного пиксельного совпадения с draw.io нет. Организационные требования сдачи выполнены частично.

Технические пределы хранения: логин 50 символов, ФИО 100, email 100; пароль для bcrypt — максимум 72 байта, без молчаливого усечения. Это не дополнительные пользовательские функции.

Изображения имеют одинаковый размер отображения, но разные исходные пиксельные размеры. Повторная компрессия и изменение оригинальных изображений при этой сверке не выполнялись; отдельную экзаменационную обработку изображений нельзя считать доказанной.

## Сравнение с draw.io

Сверены подписи, геометрия и цвета XML, а также внешний вид сайта. Это структурная и визуальная сверка, не автоматический тест пиксельного совпадения.

| Лист | Сходство | Намеренные отличия |
|---|---|---|
| Главная | Логотип слева, название по центру на широком экране, кнопки справа, слайдер с четырьмя индикаторами, текст под ним | Lorem ipsum заменён описанием портала; Search исключён; есть управление паузой |
| Копия Регистрация | Центральная форма: логин, пароль, ФИО, email, телефон; подписи и переход ко входу | Размер формы для читаемости; телефон с маской |
| Авторизация | Центральная форма из двух полей, ошибки, вход и ссылка регистрации | Search исключён; текст ссылки приведён к оригиналу |
| Страница формирования заявки | Курс, дата/календарь, оплата, отправка и возврат к заявкам | Маска даты и нативный календарь по отдельной просьбе пользователя |
| Страница просмотра заявок | Три карточки в ряд на широком экране, курс/статус/оплата/дата, отзыв в карточке, стрелки | Звёзды и Search из макета исключены в пользу оригинала; пользователь не меняет статус |
| Панель администратора | Три карточки, ФИО/курс/оплата/дата, выбор статуса, сохранение, пагинация | Поля отзыва/звёзд из макета не превращены в право администратора писать за пользователя; фильтры оставлены по оригиналу |

Шапка исправлена на #ffcc99 из draw.io. Голубые хлебные крошки #dae8fc и фиолетовые кнопки #b04f9e сохранены. Мобильная компоновка адаптирована: карточки друг под другом, три записи на логическую страницу.

## Состав функций

Исключены глобальный поиск курсов, оценки звёздами, отдельные разделы пользователей/курсов/отзывов администратора, удаление заявок, изменение ролей и добавление произвольных курсов. Сохранены текстовые отзывы, фильтры и уведомления администратора, проверка данных и разграничение доступа.

По отдельным указаниям пользователя сохранены маска телефона, маска даты, календарь и страницы по три заявки со стрелками. JS с масками и форма заявки побайтно совпадают с резервной копией до этой сверки.

Прежнее поле reviews.stars оставлено для совместимости с существующей БД и Excel-моделью. В интерфейсе его нет; старые данные не уничтожались. Удалены только два созданных для этой проверки тестовых пользователя и их тестовые записи.

## Пункты сдачи, которые остаются вне готового сайта

- Текущая версия не загружена в GitHub; коммиты по этапам не выполнены. Начальные коммиты задним числом не создавались.
- Используется локальный XAMPP, а не общий экзаменационный сервер; подключение организатора нужно проверить отдельно.
- Архивы Прил_ОЗ_КОД ... М1/М2 отдельно не предоставлены. Использованы ранее переданные изображения; совпадение состава с экзаменационными архивами не подтверждено.
- Отдельная повторная оптимизация исходных изображений не выполнялась; одинаковый размер отображения проверен.

PHP-синтаксис всех файлов проверен. Сквозные HTTP-проверки регистрации, входа, заявок, статусов и отзывов прошли. Пагинация проверена на 0/1/3/4/7 заявках, включая распределение 3/3/1, границы и отсутствие повторов. Проверены чужой доступ, CSRF и экранирование текста. Пользовательские заявки и отзывы не изменялись.
